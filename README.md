# Apartment Price Prediction

## Overview

This project investigates whether apartment prices can be accurately predicted using property characteristics from the VIT2005 dataset.

A multiple linear regression model was developed to identify the variables most strongly associated with property values and to generate future price predictions.

## Objectives

- Explore relationships between housing characteristics and apartment prices.
- Build and evaluate a predictive regression model.
- Identify statistically significant predictors of property value.
- Generate confidence and prediction intervals.

## Methods

- Exploratory Data Analysis
- Multiple Linear Regression
- Variable Selection
- Model Diagnostics
- Residual Analysis
- Confidence Intervals
- Prediction Intervals

## Key Findings

- The final model explained approximately 76.5% of variation in apartment prices.
- Several property characteristics were found to be statistically significant predictors.
- The model was successfully used to generate future property value estimates.
